## 一、项目方向

用户最初提出收集文献、结构化提取、微调模型、多 agent 协作、材料预测和实验验证的研究路线。讨论后，系统的核心任务确定为：自主完成材料预测、评估和机理探究，同时支持单独调用任一子 agent。

材料价值与多 agent 方法价值都重要，当前更侧重方法价值。用户已有完整材料实验数据，固定使用现有材料开展案例验证，不希望更换材料再完成一套实验。

系统保留跨家族比较。用户接受其他材料排名更高，并要求排名能够按研究偏好灵活调整。材料评价、排名设置和最终实验选择分别记录。

## 二、已确认的设计决策

### 2.1 目标与边界

- 输出量化评价、尽可能合理的性能区间，以及可证伪的机理假设。
- 真正灭活与出水细菌去除均为优先目标，分别定义和验证。
- ROS 任务优先顺序：浓度、生成量或速率的量化；对灭活的贡献；候选间能力排序。
- 系统面向通用研究者，当前实验条件作为一个案例档案。
- 排除通用大模型微调、统计机器学习性能回归、对抗式 agent 辩论、实验指导和论文撰写。
- 本地小模型微调保留为后期选项，限文献提取等单一任务。

### 2.2 自主执行与独立调用

保留黑板模式和脚本编排。六类子 agent 为文献提取、知识归纳、材料预测、评估筛选、性能预测、机理探究。

完整流程自动完成知识准备、跨家族生成、筛选、性能预测和机理分析。上游任务可由新文献事件或编排程序按需触发。

每个子 agent 有独立调用入口，接收目标、材料或记录、场景和预算。缺依赖时自动复用工作区信息或补充检索，不要求先运行全部前置 agent。结果格式一致，可以继续交给其他 agent。

默认不在节点等待人工确认。观察模式保留为显式开启的调试选项，正常运行只生成报告并继续。

### 2.3 缺失信息与知识缺口

系统优先检索补齐信息。可在假设下判断的结果，注明假设和影响；没有依据的字段保留未知。用户不需要逐项补齐实验细节。

缺口检索设置次数、嵌套、成本和重试上限。达到上限后本轮结束，输出可支持的部分。相关新证据或新任务到来后再重评。证据不足与材料被否定分别记录。

### 2.4 候选空间与可调整排名

候选覆盖纳米颗粒、纳米团簇、单原子等家族。材料身份拆分为活性单元与组成、配体、包覆或限域框架、导电载体、结构与负载信息。

沿用五维默认权重：ROS 潜力 30%、稳定性 20%、CDI 适配性 20%、合成可行性 15%、新颖性 15%。维度分数与证据单独留档，调整权重后重算榜单；判据、场景或证据变化时重评相应内容。

先导材料作为用户指定候选进入跨家族比较，不声称由系统自动发现，也不保证总分第一。正式方法比较提前固定规则；看到结果后调整的版本记为探索性分析。

### 2.5 三层数据库与证据边界

保留 CDI 核心、电催化先验和光催化灵感三层。光催化层仅提供灵感，不锚定当前无光场景的性能数值。

每项证据关联具体样品、原文位置、工况和测量对象。原文测量、原作者解释和系统推断分别标注。阴极氧还原证据不能直接归为先导阳极材料的能力。

### 2.6 自动检查与人工核对

近期不要求用户核对 10–20 篇论文。采用交叉提取、来源定位、单位检查、字段冲突检查和反向证据检查。第三模型仍无法解决的冲突保留为未知。

模型一致率、自动检查通过率和来源定位覆盖率分别报告。它们不等于提取准确率，双方缺失的字段单独统计。没有独立核对集时，不宣称已经验证提取准确率。

### 2.7 性能与机理输出

尽可能给出有锚点的粗略数值范围，列出工况差异和外推依据。证据不足时允许趋势或未知项，不能为了比较而补造上下界。

H₂O₂、·OH 的浓度、生成量、速率和检测信号分别记录。机理输出包含反应位置、主要路径、可能贡献、替代解释与证伪条件。定量贡献仅在证据支持时给出。

### 2.8 评估方式

当前重点是基于已有实验的回顾性评估，分为两类任务：

1. **结果留出的预测**：输入允许使用的材料和工况信息，隔离待评估的 ROS 与抗菌结果，运行后再比较。
2. **已有证据下的解释**：允许读取指定实验结果，评价证据组织与机理分析。输入过的结果不能再算独立预测命中。

多 agent 系统与单 agent 使用相同初始资料和访问边界，在相近调用预算下比较。另做交叉提取、知识缺口检索等模块的移除对照。指标覆盖数值偏差、区间覆盖与宽度、定量输出比例、证据质量、成本和稳定性。

AUC ≥ 0.8 不再作为 P3 硬性验收要求。综合总分含新颖性与合成可行性，不能直接当作杀菌有效性的标签预测。缺少杀菌报告的材料或随机组合也不能自动当作无效样本。

单一样品及其时间序列不能证明全榜单排序正确。回顾性案例、文献留出结果与方法对照分别报告结论范围。

## 三、用户提供的现有实验案例

| 项目 | 记录 |
|---|---|
| 材料 | 原始 ZIF-67 包裹铜纳米团簇 |
| 配体 | 4-巯基苯甲醛（用户简称 MBA），不按缩写替换为其他化合物 |
| 导电载体 | 炭黑 |
| 阳极与阴极 | 目标复合材料为阳极，活性炭为阴极 |
| 水体系 | 含菌纯水相 |
| 外加电压 | 1.2 V，电压定义与参比信息未明确 |
| 流动方式 | 单次流过，1 mL/min |
| 运行与采样 | 0–60 min 为装置运行时间，每隔 5 min 取出水样 |
| 初始菌浓度 | 大肠杆菌，10⁶ CFU/mL |
| 额外条件 | 无光照、无曝气、无外加氧化剂 |
| 抗菌观测 | 只有出水菌数，不含电极截留细菌的存活情况 |
| ROS 数据 | H₂O₂、·OH，有标定的浓度、生成量及清除剂实验，有对照 |
| 数据进度 | 用户确认已有材料表征、ROS 与杀菌性能的完整实验数据；本轮尚未导入核验 |
| 缺失参数 | pH、电导率、溶解氧无记录 |

现有出水计数直接支持出水 CFU 降低和 log 去除的验证，不能单独确定真实灭活程度。运行时间不等于水力停留时间；无曝气不等于无溶解氧。缺失条件保留为空，不要求用户近期补测。

## 五、旧方案到 v0.6 的关键变化

| 旧表述 | 现行决策 |
|---|---|
| 筛出最优后合成榜单第一名 | 实验对象固定，跨家族比较保留，接受其他候选排名更高 |
| 权重向先导材料倾斜但不点名 | 研究偏好公开记录，权重可调，证据和版本可追溯 |
| 只描述线性主流程 | 同时支持完整自主流程与每个子 agent 独立调用 |
| 提取与归纳不受编排调度 | 支持新文献事件和编排程序按需触发 |
| 暂停观察作为调试默认 | 正常运行自动继续，等待观察显式开启 |
| 双模型一致或第三次结果直接采用 | 加入原文定位与条件核验，无法解决的冲突保留未知 |
| 缺口第一版仅记录与检索 | MVP 需完成有预算的补充处理及受影响结果重评 |
| 一致率 ≥ 90%、AUC ≥ 0.8 作为硬门槛 | 分别报告质量与方法指标，数值门槛待评估协议定稿 |
| 每个候选都给性能区间 | 尽量量化，允许条件化趋势和未知项 |
| 实验记录导入后标为 validated | 对比完成与支持、不支持、无法判断的结论分开存储 |
| 50 篇核心文献作为固定 MVP 输入 | 先审计可用证据，再定初期规模 |

原计划文件标题为 v0.4，旧纪要称其为 v0.5。2026-10-10 已统一更新为 v0.6，以当前确认的讨论决策为准。

## 六、暂缓深入讨论的事项

以下是上一轮列出的专题。用户已要求暂缓，不作为首版开发前置条件；必要的简化接口与规则以实施计划为准。

1. 各子 agent 的输入输出、字段归属、工作区权限和独立调用依赖。
2. 来源、证据、预测、知识缺口、运行和验证记录的详细 schema。
3. 结果留出边界、单 agent 对照、模块移除对照、运行预算与评价口径。
4. 候选生成方式、材料同义词、评分聚合及裁决冲突处理。
5. 自动检索次数、嵌套深度、调用成本和重试上限。
6. 文献相关性、全文覆盖与处理范围；受限来源不阻塞其他设计工作。
7. 更细的交叉提取与角色优化。实施计划已给初版映射，现有配置文件尚未迁移。
8. 存储与检索扩展。首版默认 SQLite 与全文检索；本地推理需在目标机器实测，微调后置。

人工标注与新增实验暂不列为近期前置条件。本轮完成实施交接文档，实际代码开发由后续实施任务开展。
