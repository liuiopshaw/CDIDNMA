# 候选材料评分标准（说明 v0.2；默认数值配置 v0.1）

> 配套方案：[DESIGN_PLAN.md](DESIGN_PLAN.md) v0.6。
> 更新日期：2026-10-10。本次保留默认五维权重和数值阈值，修订证据、场景、分档解释、排名与评估规则。
> 当前配置：[config/rubric.yaml](../config/rubric.yaml) v0.1；本轮未修改配置，也未实现新流程。
> 各维度 0–10 分。以下分档是初始规则，尚未完成校准。

## 一、适用范围与证据原则

评分对象为指定场景中的候选电极材料。评分前记录电极位置、材料形态、流动方式与关键条件。未知条件保留为空；假设条件明确标注。

分数必须引用支持对应分档的证据。证据需要可定位到原文，并匹配样品、测量对象和条件。来源 ID 存在不足以证明分档成立。

证据不足与有证据表明性能差分别处理。没有依据的分数不自动填为零；无法给出关键维度分数时保留未知并进入 hold。

默认权重代表研究优先级。用户可调整权重与约束，系统保存调整原因和版本。先导材料的实验选择固定，但其得分和排名由规则与证据决定。

## 二、ROS 生成潜力（默认权重 30%）

衡量活性基元在目标电极位置和条件下的 ROS 生成能力与路径证据。

| 分数段 | 初始判据 |
|---|---|
| 9–10 | 有与目标位置、工况相关的定量 ROS 证据，测量对象及标定明确，路径有直接支持 |
| 7–8 | 在相邻电化学体系中有定性确证，路径基本明确，并说明迁移依据 |
| 5–6 | 有氧化还原活性等基础证据，支持 ROS 潜力推断，但缺少直接生成证据 |
| 3–4 | 有依据的推断较弱，或存在路径不匹配、竞争反应等明确疑点 |
| 0–2 | 有证据表明目标条件下 ROS 产率可忽略，或所提出路径不成立 |

RRDE、EPR、荧光探针、标定浓度和生成量按各自测量对象记录，不能直接视为同一种量。阴极氧还原证据不能直接记为阳极材料自身的 ROS 生成证据。

只有电势定义与条件足以支持判断时，才能按路径不可行降至低档。仅有“外加电压 1.2 V”不能替代阳极相对参比电极的电势。关键条件不足时标记缺口，而非自动判为不可行。

## 三、结构与稳定性（默认权重 20%）

衡量材料在目标水相、流动和充放电条件下的结构保持能力。

| 分数段 | 初始判据 |
|---|---|
| 9–10 | 活性组分限域或强锚定，有 50 次以上相关循环的稳定性数据，溶出满足已说明来源的适用阈值 |
| 7–8 | 有稳定性证据但循环数有限，或缺少溶出数据而有其他证据支持稳定判断 |
| 5–6 | 缺少长期数据，但限域、包覆或锚定等已知结构支持有限推断 |
| 3–4 | 有明确的溶出、团聚或结构坍塌风险，缺少缓解证据 |
| 0–2 | 有证据表明该结构在相关水相电化学条件下快速失效 |

原始框架、衍生材料和运行后的活性相分别识别。存在框架或包覆结构不自动满足高分条件。未知溶出值不能解释为低于阈值。

## 四、CDI 适配性（默认权重 20%）

衡量电极的导电性、孔结构、润湿性及与目标装置的适配程度。

| 分数段 | 初始判据 |
|---|---|
| 9–10 | 导电性良好，BET > 1000 m²/g，分级孔结构和润湿性有证据，已有 CDI 应用报道 |
| 7–8 | 导电性与比表面积良好，已用于其他相关电化学电极 |
| 5–6 | 部分性质缺失，但已有证据支持复合导电骨架后可用等有限判断 |
| 3–4 | 导电性差或比表面积低，需要较大改性才能适配 |
| 0–2 | 有证据表明其基本性质不适配，如绝缘、致密无孔或水相中粉化 |

这些阈值沿用初始分档，不代表已经证明适用于全部材料家族。粉体、复合电极与导电载体的性质分别记录，不把载体的测量值归给活性材料。

## 五、合成可行性（默认权重 15%）

按通用材料实验室条件判断文献方法的可行性，不输出具体实验操作。

| 分数段 | 初始判据 |
|---|---|
| 9–10 | 文献已有成熟室温液相方法，设备常规，原料商品化，可重复性有支持 |
| 7–8 | 需要加热或气氛控制，设备常规，文献方法说明完整 |
| 5–6 | 步骤较多，或需要溅射、CVD 等常见专用设备 |
| 3–4 | 需要非常见设备或难获取原料，替代方案不明确 |
| 0–2 | 有依据表明操作风险、原料获取或重复性构成严重障碍 |

实验室约束为可选配置，本项目默认不启用。当前先导材料已有样品这一事实可登记为案例信息，正式比较使用哪些信息须提前声明。

## 六、新颖性（默认权重 15%）

衡量候选与已报道体系的差异，保留检索式、日期、范围和相近结果。

| 分数段 | 初始判据 |
|---|---|
| 9–10 | 在已声明的充分检索范围内未发现同一 CDI 抗菌组合，且有跨领域组合依据 |
| 7–8 | 未发现同一核心组合，但同基元不同骨架或相反的相近思路已有报道 |
| 5–6 | 类似体系已报道，候选改进点明确且未被已检索结果覆盖 |
| 3–4 | 与已报道体系差异较小，主要是参数调整 |
| 0–2 | 已有对应 CDI 抗菌体系的直接报道，或差异仅在名称 |

“检索未发现”只描述当前检索结果，不能升级为全球不存在。检索不足时保留不确定性，不因为缺少文献自动给最高分。

## 七、总分、重复评分与裁决

加权总分由代码计算：Σ（维度分 × 权重）。默认权重为 30%、20%、20%、15%、15%。缺失维度不当作零，也不自动对剩余维度重新归一化。

| 裁决 | 默认条件 |
|---|---|
| pass | 总分 ≥ 7.0，且各维度 ≥ 5；关键证据完整且无未解决分歧 |
| reject | 总分 < 5.0；评分依据充分，且无须先处理的关键不确定性 |
| hold | 其他情况，包括总分处于中间区间、单维度不足、关键证据缺失或评分不稳定 |

当前配置以 5 次评分、评分 temperature 为 0 为起点。保留逐次结果，采用中位数和多数裁决的思路。标准差超过 1.0 的情况进入 hold；重复一致不构成正确性证明。

详细契约仍需明确聚合对象、标准差口径、无效调用处理和裁决冲突优先级。关键证据不足优先 hold，多数意见不能越过证据要求。具体规则须同时进入设计文档、配置和实现后，才能开展正式评估。

hold 触发有限的知识缺口处理。预算耗尽时留下未知项并结束本轮，不强制转为 reject，也不无限重复检索。

## 八、排名调整与方法评估

仅变更权重时复用有效维度分数，由代码重算总分；变更判据、场景或证据时重新评估受影响部分。保存完整候选集、权重、分数、证据与版本，展示先导材料的排名变化及原因。

正式方法比较提前固定规则。依据留出结果调整后的版本属于探索性分析，不继续当作同一份独立评估。当前先导材料可继续用于实验案例，不要求始终排第一。

综合总分表示研究优先级，不能直接等同于 ROS 数量或杀菌效力。AUC ≥ 0.8 不再作为本评分标准的硬性验收门槛。若以后建立可靠的分类标签，应单独定义任务和评估协议。

当前方法评估比较单 agent 与多 agent 的数值预测、证据处理、稳定性和成本。区间覆盖、宽度和定量输出比例共同报告。出水 CFU 降低与真实灭活分别评价，模型一致率与自动检查通过率不称为提取准确率。
